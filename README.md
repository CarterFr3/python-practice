# python-practice

Small Python programs I write myself while learning. I work through lessons on Mimo, then build things from a blank file.

## How I work
- I write the code myself. Sometimes I ask AI to explain or point out a bug (a hint, not code), and I write the fix myself.
- After each program, I read it back and explain what every line does.
- Early versions with bugs stay in the commit history on purpose, so you can see progress.

## Programs
| File | What it does | How I built it |
|------|--------------|----------------|
| `rock_paper_scissors.py` | Best-of-3 game against the computer with score tracking | Written myself; AI pointed out bugs as hints and I wrote the fixes |
| `task_list.py` | Console to-do list: add, remove, or quit | Written myself, no AI |
| `ordering.py` | Food ordering system: shows a menu, takes an item and quantity, confirms or says not found | Rebuilt from memory after working through the Mimo version; AI helped explain a bug |
| `food_order_rewrite.py` | The same idea with American and Italian menus | Rewritten from memory, peeked once at the food-type input; AI pointed me to bugs as hints |
| `cafe_order_system.py` | Cafe ordering program with a daily special and a menu with prices... (in progress) | Writing it myself from a blank file, planning in comments first... |
